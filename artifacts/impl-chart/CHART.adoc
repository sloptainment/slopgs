= slopgs — MIDI Implementation Chart
:doctype: article
:toc:
:sectnums:
:xrefstyle: short
:section-refsig!:

This document describes the MIDI behavior of the `slopgs` MIDI implementation,
an emulation of the Microsoft GS Wavetable Synth.

[#s4]
== Basic Specifications

Number of Parts:: 16
Maximum Polyphony:: 54 voices (48 sustained under continuous overload)
Effects:: None
Wavetable source:: A DLS-1 sample collection, usually `gm.dls`
Output format:: 22050 Hz, stereo, 16-bit signed PCM


[#s1]
== Receive data

`n` is the MIDI channel nibble: `0` is channel 1, `F` is channel 16.

[#s1-1]
=== Channel Voice Message

`8n kk vv` — Note Off::
* `kk` = note number (`00`–`7F`, 0–127)
* `vv` = release velocity. **Ignored.**
+
See <<ch-note-off>>.

`9n kk vv` — Note On::
* `kk` = note number (`00`–`7F`, 0–127)
* `vv` = velocity (`01`–`7F`, 1–127)
+
See <<ch-note-on>>.

`An kk vv` — Polyphonic Key Pressure:: **Ignored.**

`Bn cc vv` — Control Change:: See <<scc>>.

`Cn pp` — Program Change::
* `pp` = program number (`00`–`7F`, 0–127)
+
Selects the instrument from `pp` and the current Bank Select value (<<scc>>).

`Dn vv` — Channel Pressure:: **Ignored.**

`En ll mm` — Pitch Bend Change::
* `ll` = LSB, `mm` = MSB
* Value = `mm` × 128 + `ll` (14-bit, 0–16383)
* Center = `00 40` (8192)
+
RPN 0 sets the range (<<scc>>). See <<ch-bend>>.

[#scc]
=== Control Change

The synthesizer recognizes only the controllers below. It ignores all other
controller numbers. For the default values, see <<reset-table>>.

`Bn 00 mm` — Bank Select MSB::
`Bn 20 ll` — Bank Select LSB::
Sets the bank for the next Program Change. Notes that already sound do not
change.
+
**GS mode only.** When GS mode (<<roland-sysex>>) is off, the synthesizer ignores these messages
and does not keep the value.

`Bn 01 vv` — Modulation:: Recognized. See <<ch-mod>>.

`Bn 06 mm` — Data Entry MSB::
`Bn 26 ll` — Data Entry LSB::
Sets the value of the selected RPN (see RPN, below). If RPN 0, 1 or 2 is not
selected, these messages have no effect.

`Bn 07 vv` — Channel Volume:: Recognized.

`Bn 0A vv` — Pan::
Recognized. `00` = left, `40` (64) = center, `7F` = right. See <<ch-pan>>.

`Bn 0B vv` — Expression:: Recognized.

`Bn 40 vv` — Hold 1 (Sustain)::
* `00` = off (pedal up)
* `01`–`7F` = on (pedal down)

`Bn 5B vv` — Effects 1 Depth (Reverb Send):: **Ignored.**

`Bn 5D vv` — Effects 3 Depth (Chorus Send):: **Ignored.**

`Bn 62 ll` — NRPN LSB::
`Bn 63 mm` — NRPN MSB::
Deselects the current RPN. These messages do not select a parameter.

`Bn 64 ll` — RPN LSB::
`Bn 65 mm` — RPN MSB::
Select the parameter that Data Entry (CC6/CC38) sets:
+
[options="header",cols="1,2,2,2"]
|===
| RPN (MSB LSB) | Parameter | Data Entry | Applied
| `00 00`
| Pitch Bend Sensitivity
| MSB = semitones. Default 2.

LSB is ignored.
| Immediately, also to sounding notes.
| `01 00`
| Fine Tuning
| MSB and LSB: −100 … +99 cents.
| At the next Note On.
| `02 00`
| Coarse Tuning
| MSB: −64 … +63 semitones.

LSB is ignored.
| At the next Note On. Melodic Parts only.
| `7F 7F`
| Null (no parameter)
| No effect.
| —
| Other
| —
| Stored. No effect.
| —
|===

`Bn 78 00` — All Sound Off::
Releases all sounding notes on the channel, also the notes that the pedal
holds.

`Bn 79 vv` — Reset All Controllers::
Resets Expression, Pitch Bend, Modulation and the sustain pedal. If `vv` is
not `00`, it also resets Channel Volume and Pan. See <<ch-reset>>.

`Bn 7A 00` — Local Control:: **Ignored.**

`Bn 7B 00` — All Notes Off::
Releases all sounding notes on the channel. Notes that the pedal holds
continue until the pedal is up.

`Bn 7C 00` — Omni Off::
`Bn 7D 00` — Omni On::
**Ignored** (<<s1-2>>).

`Bn 7E mm` — Mono On::
Sets the channel to mono. Releases all sounding notes on the channel, also
the notes that the pedal holds. `mm` is ignored.
+
In mono, each Note On first releases all notes on the channel, also the notes
that the pedal holds. Notes do not glide.

`Bn 7F 00` — Poly On::
Sets the channel to poly. Releases all sounding notes on the channel, also
the notes that the pedal holds.

[#s1-2]
=== Channel Mode Message

The synthesizer always operates in *Omni Off*. It ignores Omni On and Omni Off.

CC126 and CC127 set Mono or Poly for each channel. The default is *Poly*.

[#s1-3]
=== System Common Message

**Ignored**: Song Position Pointer, Song Select, Tune Request.

`slopgs` plays a Standard MIDI File on its own clock. It does not use sync
messages.

[#s1-4-rt]
=== System Real Time Message

`F8` Timing Clock, `FA` Start, `FB` Continue, `FC` Stop:: **Ignored.**

`FE` Active Sensing:: **Ignored.**

`FF` System Reset::
Sets the values in <<reset-table>>. Some values do not reset. See
<<ch-reset>>.

[#s1-4]
=== System Exclusive Message

The synthesizer recognizes the four messages below. It does not check the
device ID (`dev`). It ignores all other System Exclusive messages.

[cols="1,2a"]
|===
| `F0 41 dev 42 12 aa bb cc dd`…`dd sum F7`
| Roland GS message (DT1).

* `aa bb cc` = address (<<roland-sysex>>)
* `dd`…`dd` = data
* `sum` = checksum. **Not checked.**
| `F0 7E dev 09 01 F7`
| GM System On.

Resets the device and clears GS mode. Loads the instrument set.
| `F0 7E dev 09 02 F7`
| GM System Off.

Resets the device and clears GS mode. **Unloads the instrument set**: no note
sounds until GM System On or System Reset.
| `F0 7F dev 04 01 ll mm F7`
| Master Volume.

Uses `mm` only. `ll` is ignored.

Changes apply on next notes (<<mastervol>>).
|===

[#roland-sysex]
==== Roland Messages

Put these addresses in `aa bb cc` of the Roland GS message.

NOTE: When GS mode is off, the synthesizer ignores all addresses except GS
Reset (`40 00 7F`).

[options="header",cols="2,3,3a"]
|===
| Address | Parameter | Effect
| `40 00 7F`
| GS Reset
| Resets the device and sets GS mode.
| `40 1n 02`
| RCV CHANNEL
| Sets the MIDI channel that Part `n` receives. `01`–`10` = channel 1–16.
`00` is ignored. Stays until the next reset.
| `40 1n 15`
| USE RHYTHM PART
| `00` = melodic Part. Other values = rhythm (drum) Part.

Also resets all channels. See <<ch-reset>>.
| `40 1n 40`
| Scale Tuning
| 12 values for Part `n`, C to B. `40` = no change. See <<ch-scale>>.
| `40 1n` _other_
| Other Part parameters
| **Ignored.**
|===

The synthesizer ignores all other addresses. Examples:

* System Parameters (`40 00 00`–`06`: Master Tune, Master Volume, Master
Key-Shift, Master Pan)
* Drum Setup Parameters (`41 xx xx`)
* Bulk Dump (`48 xx xx`, `49 xx xx`)
* Display Data (model ID `45`, `10 00 xx`)

It also ignores RQ1 (data request) messages.

[#s3]
== MIDI Implementation Chart

Basic Channel:: The MIDI channel that each of the 16 Parts receives. Parts
are numbered `0`–`15`, as the `n` in the `40 1n xx` addresses (<<s1-4>>).

Mode:: The MIDI Mode messages (Omni On/Off, Mono/Poly). `slopgs` always
operates in Omni Off. You can set Mono or Poly for each channel.

Note Number / True Voice:: The note numbers that the synthesizer accepts, and
the note numbers that it plays. Note 60 is middle C.

Velocity:: If the velocity of Note On and Note Off has an effect.

After Touch:: `Key's` = polyphonic (per-note) aftertouch. `Ch's` = channel
aftertouch.

Control Change:: See <<s3-2>> and <<scc>>.

Program Change:: The program numbers that a Program Change can select. This
is the message value: one less than the instrument number on most instrument
lists.

System Exclusive:: See <<s1-4>>.

System Common, System Real Time:: Sync messages. Not used, except System
Reset (`FF`).

[#ch]
== Synthesizer Characteristics

[#ch-polyphony]
=== Polyphony

The synthesizer has 54 voices. From the 49th voice, *it releases old voices
faster than a steal-oldest policy does*.

A new note on a key that still sounds on the same channel *cuts the earlier
note*. This also occurs when the earlier note is in its release.

The sample collection may let patches overlap. If so, both notes sound anyway.

A voice that is cut this way, or by an exclusive group in a drum kit, fades
to silence in ~15ms or less. It does not click.

[#ch-envelopes]
=== Envelopes

Levels fade at a *constant rate* in decibels.

The sample collection can *scale these times for each note*. Higher notes can
decay faster. On some patches, harder notes attack faster.


[#ch-note-on]
=== Note On

Velocity behavior::
Velocity uses a fixed curve: amplitude follows the square of velocity/127.
+
Velocity may also change the attack (e.g. a harder note attacks
faster), if the sample collection specifies the patch this way.

CC behavior::
In one instant, the synthesizer first collects all the Pitch Bend, Volume,
Expression, Pan and Modulation values. It then starts up the note with
the values on or before the Note On.
+
If in the same instant those values change after the Note On, the note will
glide to those new values.

[#ch-note-off]
=== Note Off

A released note fades at the rate of its patch's release, which does not change with the level at release. Therefore a note that
is released at a lower level becomes silent sooner.

The synthesizer does not make short releases longer: a 10 ms release stops in
10 ms.

The fade can start up to approximately 25 ms before the Note Off (see
<<ch-timing>>).

[#ch-bend]
=== Pitch Bend

Pitch Bend changes all sounding notes on the channel. This includes rhythm
(drum) Parts, with the RPN 0 range of their channel.

RPN 0 accepts all values (`00`–`7F`). The bend itself stops at ±48
semitones.

[#ch-timing]
=== Controller timing

Pitch Bend, Modulation, Channel Volume, Pan and Expression do not change in
one step. Each change glides to the new value in approximately 25 ms or less
(with `gm.dls`). The glide can start a short time before the message.

If a change and its reverse both occur in this time, you do not hear the
change. Thus very fast Volume or Expression gates become soft. They never cut
to silence.

[#ch-mod]
=== Modulation

Modulation adds vibrato. Where the sample collection sets it, Modulation also
adds tremolo (a change in loudness). The sample collection sets the depth.

Some patches have vibrato or tremolo when Modulation is `00`. In `gm.dls`,
examples are Tremolo Str, Vibraphone, Shakuhachi, Flute and Contrabass.

Each patch sets its own rate and delay. If a patch does not set them, the
rate is 5 Hz and there is no delay.

[#ch-pan]
=== Pan

The pan law is constant power: each side is attenuated by
`10·log10(position)`. At center, each side is approximately 3 dB down. At
hard pan, the far side is approximately 25 dB down. It is not silent.

Each side has a maximum level (<<ch-ceiling>>). A loud Part can be at this
maximum on both sides near center. Then Pan has no effect until the far side
falls below the maximum. This range is wide at high Channel Volume and
Expression, and narrow at low levels. At low levels, the full sweep is
smooth. Near the maximum, the side that you pan toward does not become
louder.

[#ch-ceiling]
=== Loudness ceiling

Each voice has a maximum output level. A voice can reach it before velocity,
Channel Volume and Expression are all at maximum. Above this level, a harder
note is not louder. It can still have a different attack or sample layer.
The patch's velocity sensitivity sets how wide this range is.

The ceiling also applies to the envelope. A note above the ceiling stays at
full level until its envelope falls by the amount above the ceiling. Thus a
loud note gets to full level sooner and starts to decay later. It sounds
longer than a soft note.

[#ch-reset]
=== Reset behavior

No reset changes:

* Pitch Bend Sensitivity (RPN 0)
* The selected RPN

Reset All Controllers (CC121) does not change Bank, Program, Fine Tuning
(RPN 1) or Coarse Tuning (RPN 2).

GS Reset, GM System On, GM System Off and
System Reset set Fine Tuning and Coarse Tuning to 0.

System Reset (`FF`) does not change the instrument of each Part. Only GS
Reset and GM System On/Off set all Parts to program 0.

*Exception:* System
Reset can discard a Program Change from up to approximately 46 ms before it.

USE RHYTHM PART (<<roland-sysex>>) stops all notes on all channels
immediately. It also resets Channel Volume, Pan, Expression, Pitch Bend and
Modulation on all channels. Bank and Program do not change.

[#ch-scale]
=== Scale Tuning

Each of the 12 values tunes one note name (C, C♯, D … B) by the value minus
`40`, in cents: `00` = −64 cents, `40` = no change, `7F` = +63 cents. This
also applies to rhythm Parts.

The synthesizer applies Scale Tuning at Note On, as for Fine Tuning. Sounding
notes do not change.

The data always starts at C. If `F7` ends the message early, the synthesizer
discards the last value before `F7`. It keeps the values before that one.

Other Part addresses (`40 1n` _other_) do not change Scale Tuning.

[#mastervol]
=== Master Volume

Master Volume changes take effect only upon a next
Note On, not immediately. Fader effects cannot,
for example, take effect on a held note.

Channel Volume and Expression still work as expected
and change currently-sounding notes (<<ch-timing>>).
